# Чек-лист тестирования AppGroupProbe на iPhone

Процедура проверки реального обмена данными между приложением и виджетом
через App Group после подписи IPA в GBox.

**Перед началом:** скачай артефакт `AppGroupProbe-unsigned-ipa` из GitHub
Actions, подпиши его в GBox своим сертификатом и профилем `EYD9KX` и установи
на iPhone.

---

## Этап 0. До установки — аудит IPA (по желанию, на Mac)

```sh
./scripts/audit-ipa.sh AppGroupProbe-unsigned.ipa
```

Зафиксируй в отчёте:
- [ ] SHA-256 unsigned IPA
- [ ] App Groups в entitlements main и widget
- [ ] `AppGroupIdentifier` в обоих Info.plist

⚠️ **Если есть экспорт переподписанной IPA из GBox** — прогони тот же скрипт
по ней ДО установки и сравни (см. раздел «Сравнение до/после GBox»).

## Этап 1. Установка

- [ ] IPA устанавливается через GBox без ошибок
- [ ] Приложение отображается на домашнем экране
- [ ] Иконка и имя: AppGroupProbe

## Этап 2. Запуск основного приложения

Открой приложение и проверь раздел «Идентичность процесса»:

- [ ] **Bundle ID** показывает `app.yam53.taro5888` (или с чем GBox подписал —
      если другое, зафиксируй фактическое значение)
- [ ] **App Group** показывает `group.c2fefdd0db2e255e.1`

Раздел «Общий контейнер»:

- [ ] **containerURL** показывает путь `/private/group.container.../...`
      (НЕ «nil»)
- [ ] **Доступ**: «✅ контейнер получен»

> Если containerURL == nil → GBox не сохранил App Group в entitlements
> основного приложения. Это первый ключевой результат эксперимента.
> Дальше можно не проверять — сначала разберись с подписью (см. README, раздел
> «Диагностика ошибок»).

## Этап 3. Запись и чтение в приложении

- [ ] Нажми **«Записать тестовые данные»**
- [ ] Статус: «✅ Записано поколение #1»
- [ ] В разделе «Данные в App Group» появился `uuid: …`, `generation: 1`
- [ ] Нажми **«Перечитать данные»** — те же значения
- [ ] Нажми **«Записать тестовые данные»** ещё раз — `generation: 2`,
      новый uuid

## Этап 4. Виджет

- [ ] Добавь виджет AppGroupProbe: долгое нажатие на пустом месте домашнего
      экрана → «+» → найди **AppGroupProbe** → размер Small или Medium
- [ ] Виджет появляется в галерее (если нет — расширение не установилось/
      не зарегистрировалось)
- [ ] Виджет показывает **«App Group OK»** и uuid
- [ ] **Uuid в виджете совпадает с uuid последней записи в приложении**
      (сократи глазами по первым 8 символам)
- [ ] В виджете тот же номер поколения

> Это главный критерий успеха: два процесса прочитали один файл из одного
> системного контейнера.

## Этап 5. Обновление данных

- [ ] В приложении нажми «Записать тестовые данные» (generation 3)
- [ ] Нажми «Обновить виджет (WidgetCenter)»
- [ ] Подожди до ~30 секунд (timeline обновляется не мгновенно)
- [ ] Виджет показывает новый uuid и generation 3
- [ ] Если не обновился сразу — проверь через 30 минут (политика timeline
      — 30 минут); отсутствие мгновенного refresh НЕ означает отказ sandbox

## Этап 6. Перезагрузка устройства

- [ ] Перезагрузи iPhone
- [ ] Открой приложение: «Перечитать данные» → те же uuid/generation
      (последняя запись)
- [ ] Виджет после перезагрузки показывает те же данные

## Этап 7. Повторная подпись / обновление (опционально, если GBox экспортирует IPA)

- [ ] Переподпиши ту же IPA повторно в GBox и установи поверх
- [ ] Данные в App Group сохранились (uuid/generation прежние)
- [ ] Виджет читает их же

## Сравнение до/после GBox (если есть экспорт IPA)

Прогони `scripts/audit-ipa.sh` на обеих версиях и заполни:

| Поле | Unsigned CI | После GBox |
|---|---|---|
| Main Bundle ID | app.yam53.taro5888 | |
| Main application-identifier | (ad-hoc, нет) | |
| Main App Groups | group.c2fefdd0db2e255e.1 | |
| Widget Bundle ID | app.yam53.taro5888.widget | |
| Widget application-identifier | (ad-hoc, нет) | |
| Widget App Groups | group.c2fefdd0db2e255e.1 | |
| Widget .appex в PlugIns | да | |
| Main embedded profile | нет | |
| Widget embedded profile | нет | |
| codesign --verify main | (ad-hoc) | |
| codesign --verify widget | (ad-hoc) | |

| 4 | Виджет есть в галерее | ☐ |
